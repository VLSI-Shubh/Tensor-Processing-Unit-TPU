# doc

Reference material for the project.

- [1978-cmu-cs-report-kung-leiserson.pdf](1978-cmu-cs-report-kung-leiserson.pdf): H. T. Kung and C. E. Leiserson, Carnegie Mellon University report, 1978. The original description of systolic arrays.
- [1982-kung-why-systolic-architecture.pdf](1982-kung-why-systolic-architecture.pdf): H. T. Kung, "Why Systolic Architectures?", IEEE Computer, 1982. The shorter paper, and the better place to start. It explains why data flowing through a regular array saves memory bandwidth.
- [Background video](https://www.youtube.com/watch?v=jll-Xc9Gpnw) that the project was started from.
